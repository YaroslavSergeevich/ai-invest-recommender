# News Classifier — сервис классификации новостей

Веб-сервис на Python (FastAPI) для трека «Новостная аналитика». Принимает новость и её источник в JSON,
отправляет нейросети (через OpenAI-совместимый шлюз) промпт, новость и файл `industries.csv`
и возвращает:

- список отраслей (полные коды ОКВЭД, только из `industries.csv`);
- страну;
- регион и город (только если страна — Россия);
- источник новости;
- краткую выжимку новости.

---

## 1. Состав проекта

```
news_classifier/
├── main.py            # код сервиса
├── industries.csv     # справочник отраслей
├── requirements.txt   # зависимости Python
├── .env               # ваш API-ключ
└─── README.md         # эта инструкция
```

Файл `industries.csv` должен лежать **рядом с `main.py`** — сервис находит его сам, прописывать путь
в `.env` не нужно.

Формат `industries.csv` (разделитель `;`):
```
ОКВЭД 2 знака;Подробный ОКВЭД;Вид деятельности
01;01.11;Выращивание зерновых (кроме риса), зернобобовых культур и семян масличных культур
62;62.01;Разработка компьютерного программного обеспечения
и т.д.
```

## 2. Запуск

Команды даны для Windows (PowerShell) и Linux/macOS. Все выполняются из папки проекта.

### Шаг 1. Перейдите в папку проекта
```cmd
cd C:\Ваш_Путь
```

### Шаг 2. Активируйте окружение
```cmd
.venv\Scripts\аctivate
```
В начале строки терминала должна появиться надпись `(.venv)`.

### Шаг 3. Создайте файл `.env`
В папке проекта **рядом с `main.py`** создайте файла `.env`.

Как создать:
Правая кнопка мыши, "Создать", "Текстовый документ", переименуйте файл в `.env` (не `.env.txt`, не `env`)
Окройте файл и вставьте: LLM_API_KEY=ВАШ_КЛЮЧ (без пробелов вокруг равно!!!)
ИЛИ
```cmd
echo LLM_API_KEY=ВАШ_КЛЮЧ> .env
```

### Шаг 4. Запустите сервис
```cmd
uvicorn main:app --port 8000
```
Окно терминала не закрывайте, пока сервис нужен. Остановка — `Ctrl + C`.


### Повторный запуск (после перезагрузки или в новом терминале)
```cmd
cd C:\Ваш_Путь
.venv\Scripts\activate
uvicorn main:app --port 8000
```

## 3. Формат входного JSON
`POST http://localhost:8000/classify`, заголовок `Content-Type: application/json`. Тело — JSON-объект.
### Поля
```json
{
  "source": "<источник новости>",
  "title": "<Заголовок новости>",
  "text": "<Текст новости>"
}
```
## 4. Формат корректного ответа
Ответ `200 OK`, JSON-объект:
```json
{
  "id": null, #id будет присваиваться сервером
  "industry_id_list": ["<Подробный ОКВЭД>", ...],
  "region": "<Регион новости>", #если Россия, иначе null
  "city": "<Город новости>", #если Россия, иначе null
  "country": "<Страна новости>",
  "source": "<Источник новости>",
  "text": "<Выжимка из новости>"
}
```

## 5. Коды ошибок
Тело ошибки: `{"detail": "описание"}`.
401 - Неверный API ключ
422 - Тело запроса не JSON-объект, либо в нём нет данных новости
429 - Исчерпан дневной бюджет ключа (`Budget has been exceeded`)
502 - Шлюз недоступен или вернул ошибку (оба адреса)
502 - Нейросеть дважды вернула ответ, который не удалось разобрать как JSON

## 6. Служебные эндпоинты
`GET /health` - Состояние сервиса: загружен ли справочник и `.env`, найден ли ключ, адреса шлюза
`GET /budget` - Остаток бюджета ключа (`spend`, `max_budget`, `remaining`, `budget_reset_at`) через `/key/info` шлюза
`GET /models` - Модели, доступные ключу на шлюзе

`/budget` и `/models` используют тот же ключ, что и `/classify`.

## 7. Переменные окружения
Задаются в `.env`.
`LLM_API_KEY` - API-ключ команды (также читаются `OPENAI_API_KEY`, `GEMINI_API_KEY`) ОБЯЗАТЕЛЕН!!!
`LLM_MODEL` - `google/gemma-4-26b-a4b-it` (Модель по умолчанию)
`LLM_BASE_URL` - адрес шлюза
`LLM_JSON_MODE`, `1` — просить у шлюза принудительный JSON-режим ответа (если модель его поддерживает)
`LLM_TIMEOUT` - Таймаут запроса к модели, секунды
`LLM_MAX_TOKENS` - Лимит токенов ответа
